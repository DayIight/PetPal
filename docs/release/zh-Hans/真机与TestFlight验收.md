# 真机与 TestFlight 验收

当前状态（2026-10-11）：用户暂无 TestFlight 构建；本轮只记录自动化及模拟器结果。可以先经 Xcode 安装进行真机功能验收，之后补 TestFlight 分发验收。不得把“待执行”改为“通过”而不附实测证据。

## 经 Xcode 安装到自己的 iPhone / iPad

1. 用 Xcode 打开仓库根目录 `PetPal.xcodeproj`，选择 `PetPal` scheme。
2. 用数据线连接设备、解锁并信任电脑；按设备提示启用 Developer Mode。Xcode 设置中添加自己的 Apple 账户。
3. 在 App 和 Widget 两个 target 的 Signing & Capabilities 选择同一真实 Team，使用自己可用的 Bundle ID。两端 App Groups 必须为同一已注册组；同时修改 `M8_Widget/WidgetSnapshot.swift` 的 appGroupID 和两份 entitlements。当前示例 `group.com.petpal.prototype` 不是你的自动可用权限。
4. 选择已连接设备，点击 Run。签名或 App Group 报错时按该 Team 的可用能力处理；当前带 Widget/App Group 的配置不能保证免费 Personal Team 可直接签名。需要正式分发时使用相应 Apple Developer Program 资格。
5. 本次功能验收不传 `--petpal-preview`，从空档案或实际测试资料开始；不要覆盖唯一的正式资料，先导出完整备份。
6. 记录 Xcode 版本、设备具体型号、系统版本、App 版本/构建、安装方式、结果与截图。Xcode Run 不验证 App Store Connect 上传、TestFlight 邀请与升级安装。

操作参考：[Apple：在模拟或实体设备运行 App](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices)。
