# App Review 说明草稿

版本 1.0。以下功能说明可用于 App Store Connect 审核备注；审核联系人的真实姓名、电话、邮箱和构建号需由发布者填写，不应将本文件当成已提交记录。

## 可粘贴的功能说明

PetPal 是无需登录的本地宠物日常与健康记录工具，没有测试账号或远程服务依赖。首次打开在「今日」显示可跳过的引导。创建档案后可保存记录和配置提醒，随时在「我的」新增或编辑宠物。

测试路径：
1. 今日 → 创建宠物档案，填写昵称与品种 → 保存。
2. 今日 → 记第一条日常，选择模板并填写必填项 → 保存。记录可选择过去的发生日期。
3. 设置提醒 → 保存。系统此时才询问通知权限；拒绝权限仍可保存并查看 App 待办。已保存提醒可在「记录 → 管理提醒」编辑、暂停或删除。
4. 成长 → 导出 PDF → 选择全部日期或自定义范围 → 生成并分享 PDF。报告只包含当前宠物，空数据项目会标注；报告用于整理主人资料，不提供诊断和治疗建议。
5. 我的 → 数据备份 → 导出完整备份或从文件恢复。恢复会替换当前数据，并保留恢复前本机副本。
6. 我的 → 隐私与支持，查看离线政策并复制反馈模板。反馈不自动发送。

相机权限仅在用户主动拍照时请求，照片选择使用系统选择器。资料保存在本机，没有账号、社区、聊天、付费或广告，也没有开发者服务器的数据上传。报告和备份只通过用户选择的系统分享/文件服务导出。
