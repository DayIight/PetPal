## 四、本轮新发现的问题与风险

### R-01（低危·疑似 bug）超长评论渲染

发送约 500 字评论后，新评论行占据布局高度但未在视图树实例化（键盘展开态 + 离屏懒加载叠加）。测试已绕开该场景，**需人工走查「发超长评论后滚动列表可见性」**。若复现，怀疑 `LazyVStack` 行高计算与键盘避让的组合问题。

### R-02（低危·测试稳定性）日历 UI 用例连跑飘绿

`test_calendarShowsTodayRecord` 在 10 条 UI 测试连跑时偶发断言超时，单跑必过。疑似模拟器在长时间连跑后响应变慢。建议：关键断言的 `waitForExistence` 超时从 3s 提到 5s，或引入显式等待动画结束的 helper。

### R-03（低危·覆盖盲区）三个视图文件

`PetFormView`（0%，模拟器持久化数据导致建档路径被跳过——属测试数据依赖，建议测试启动时加 `-ResetPetPal` 环境重置参数）、`CustomTemplateViews`（0%，自定义模板无 UI 测试）、`MessagesView`（8.7%，占位页可接受）。前两者建议补脚本。

### R-04（技术债·文件粒度）

`DashboardView.swift`（573 行）、`RecordsHomeView.swift`（508 行）偏大，建议后续按视图区块拆分（如 `DashboardView` 拆出 `HeatmapView`/`TimelineSection`/`PDFBuilder`）。不影响功能，影响可维护性。

### R-05（环境）开发机缺 Simulator GUI

`Simulator.app` 未随 Xcode 安装（无头模拟器正常，故测试不受影响）。人工点界面需在 Xcode 直接 ⌘R，或 Xcode → Settings → Platforms 重装组件。

### 已闭环的本轮新发现（留档）

- `AvatarStore` 在 @3x 屏输出 3240px（渲染器默认跟随屏幕 scale）——已修复 `format.scale = 1`
- `test_createPet_thenLogFeeding` 假绿（必填项未选）——已修复为真实保存 + sheet 关闭断言
- `CalendarDay` 随机 UUID 身份致无限重渲染——已修复为稳定身份（`blank-N` / `d-<时间戳>`）
- `test_exportPDF` 依赖「无体重数据」环境假设——已消除测试顺序耦合
