# PetPal 日常照护增强实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 完成本轮选定的五项本地照护功能及备份、删除、提醒与分享联动。

**Architecture:** Core Data V4 新增通用 `CDCareItem`，四种类型载荷共用保存事务。文件以随机名称存于现有媒体目录；疗程扩展共享日期规则；快捷/搜索与资料/PDF、疗程按文件所有权分工。

**Tech Stack:** Swift 5、SwiftUI、Core Data、PDFKit、UIKit；iOS 16 起，不新增外部依赖。

**Spec:** [日常照护增强设计](PetPal_日常照护增强设计_2026-10-17.md)

## Global Constraints

- 全部功能离线可用、限定当前宠物；不接入账号与云同步。
- 保存失败回滚，数据库保存成功后再清理旧媒体；新增数据进入完整备份。
- 快捷项最多 6 个；医疗 PDF 最多 20 MiB/200 页；疗程 1–6 个时间、最长 180 个日历日。
- 保留当前未提交的上线复评文档；本轮不发布、不上传、不覆盖历史文档。

## Review Focus

- 复制历史记录不得继承旧照片、旧任务完成身份和下次日期。
- 多宠物切换、备份恢复和删除后不能展示其他宠物的新增资料。
- 附件导入中断或数据库保存失败不能残留孤立文件或删除原件。
- 疗程边界、时区/夏令时和编辑不能提前/越界通知或破坏历史完成记录。
- 分享必须限定选定宠物及勾选内容；长文本完整，不悄悄导出空数据。
