# PetPal 日常照护增强交付记录 · 2026-10-17

## 范围

按用户选择实现五项本地功能：常用快捷、记录搜索筛选、医疗资料夹、用药疗程、照护交接卡。沿用 iOS 16 起的 SwiftUI / Core Data 架构，没有新增第三方依赖。微信、手机号登录及多设备云同步另行实施，本轮未接入。

工作分支为 `codex/care-tools`，基线 `05a432a76c54ef0ffdf59bc3492d39eda28c56a3`。保留此前的上线复评文档。功能验收完成后，用户授权将当前改动提交并推送至 GitHub 功能分支；App 发布仍按下方验收边界执行。

## 功能与入口

| 功能 | 入口 | 交付行为 |
|---|---|---|
| 常用快捷 | 今日 → 管理常用快捷 | 每宠物最多 6 项，命名和编辑独立内容快照，可从历史记录建立；打开时新建事件身份和当前时间，清除照片、旧任务身份和日期计划，显式保存才写入 |
| 搜索与筛选 | 记录 → 搜索 / 筛选 | 搜索类型、模板、答案及备注，叠加类型和含首尾全天的日期范围；限定当前宠物，空结果和非法日期提示，清除恢复原视图 |
| 医疗资料夹 | 我的 → 医疗资料夹 | PDF / JPEG / PNG 导入，元信息维护、原件预览及系统分享，可关联同宠物健康记录；PDF 上限 20 MiB / 200 页，图片上限 10 MiB / 4096 px / 1600 万像素，拒绝加密或不可读文件 |
| 用药疗程 | 记录 → 管理提醒 → 用药疗程 | 主人填写药名、用量说明、含首尾起止日期、每日 1–6 个不同时间，最长 180 个日历日；支持编辑、暂停/恢复、结束、删除和历史，实际服药需记录，跳过明确未服药 |
| 照护交接卡 | 我的 → 照护交接卡 | 保存饮食、日常照护、注意事项和紧急联系人；过敏、进行中用药、兽医默认关闭，可选择并预览后生成分页 PDF；不附带芯片号、医疗原件或其他宠物资料 |

PDF 医疗文件保留导入内容；医疗图片按方向归一化存储。导入通过安全作用域和文件协调异步限量读取，取消或保存失败清理新文件，删除元数据成功后再清理原件。删除关联健康记录只解除资料关联，保留文件。

疗程每个时间关联一条有起止边界的每日提醒，与 App 和 Widget 共用日期计算。未变时间保留提醒身份，移除时间停用并保留历史关联；疗程和提醒同事务保存。通知与其他提醒共用最多 64 条待发送预算，页面显示滚动安排截止日，需要定期打开 App 补排。

## 数据与兼容

- Core Data V4 新增 `CDCareItem`，按宠物存储四类 JSON 载荷，保留 V1–V3 模型迁移路径。写入校验载荷身份、类别和真实宠物归属。
- 完整备份导出 v2、兼容 v1。包含新增照护载荷及医疗文件，恢复校验载荷、宠物、健康记录、提醒和媒体引用；医疗文件随机重命名并同步更新载荷。损坏或缺少文件时保留原库。
- 删除宠物同事务级联清理照护项，保存成功后清理医疗文件；保存失败回滚。就医报告原有导出行为保留。
- 全部资料保存在本机；完整备份未加密，联系人和医疗文件也在备份中。卸载会清除本机数据和本机备份，仍需主动导出到可信位置。
