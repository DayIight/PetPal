# PetPal 社区版 App Icon

## （1）设计理念

以「来和我交个朋友」为设计主题。一只戴蝴蝶领结、眨眼微笑的奶油白狗狗，主动向用户表达友好；右上方的爱心对话气泡表达交流、认同与社区归属。拟人化由表情和穿戴共同承担，不依赖说明文字。

为 20–35 岁都市养宠人群使用克制的大色块、圆润轮廓和轻微暖橙渐变。温暖、信任和轻松愉悦是设计意图，未经用户调研量化验证。

## （2）视觉元素拆解

| 元素 | 设计与作用 | 60×60px 下的表现 |
|---|---|---|
| 单只狗狗 | 奶油白圆脸、可可棕垂耳，主体偏左下，为气泡留白 | 大色块保留物种轮廓 |
| 眨眼与微笑 | 一只睁眼、一只弧线眼，嘴角上扬，体现主动打招呼的拟人表情 | 眨眼线约 1.4px，嘴线约 1.2px |
| 蝴蝶领结 | 对称、实心、无细碎纹样的穿戴配饰 | 宽约 9.8px，可辨认蝴蝶形 |
| 爱心对话气泡 | 奶油白气泡＋暖橙实心爱心，尾部朝向狗狗 | 气泡宽约 16.2px，爱心宽约 7.3px |
| 背景 | 全出血暖橙，左上到右下轻微渐变 | 不增加纹理或装饰噪声 |

已检查实际 60px 栅格图及浅、深背景组合预览。预览板下方图标在原始图片中为 60×60px；聊天界面缩放整张预览图时，其显示尺寸会随之改变。

## （3）iOS 与 Android 规范适配说明

### iOS

- 主画布为 **1024×1024px**；`AppIcon-1024.png` 是 RGB、不含 Alpha 通道的正方形 PNG，保留完整四角。
- 已写入 `PetPal/Assets.xcassets/AppIcon.appiconset/AppIcon.png`，复用项目已配置的 `AppIcon` 资产名称及 universal / iOS / 1024x1024 槽位。
- 原图标备份于 `../Archive/AppIcon-before-community.png`。
- 系统负责施加圆角。预览使用连续超椭圆近似遮罩，仅用于设计展示，不声称与系统遮罩逐像素一致，也不将圆角写入提交 PNG。
- 浅色背景为 `#F6F3EE`：暖橙边缘清晰，奶油白主体柔和；深色背景为 `#24272B`：暖橙主体更突出，保持同一配色。两张图是同一个默认图标在不同背景上的效果，并非 iOS 深色或染色外观变体。
- Apple 当前亦提供 Icon Composer 分层图标流程。本次交付沿用本项目现有 PNG Asset Catalog；另附独立前景和背景 SVG，供后续分层制作使用，未交付 `.icon` 文件。

规范依据：[Apple — App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons)，核对日期：2026-10-04。

### Android 自适应图标

- 前景、背景各为 **108×108dp**；背景铺满，前景外围透明。由启动器决定圆形、圆角矩形等遮罩。
- 四周各 **18dp** 为系统裁切与运动效果预留区域，中央可视区域为 **72×72dp**。本设计进一步按中心 **直径 66dp 的安全圆**约束全部前景，避免把 66dp 外接正方形的四角误当成安全区域。
- 1024 工作画布中的安全圆：圆心 `(512,512)`、半径约 `312.889px`；66dp 对应约 `625.778px`。
- Android 前景独立排版：先把原图前景包围盒中心 `(515,476.5)` 移至原点，再缩放至 **64.64%**，最后移至 `(512,512)`。对应 SVG 变换：`translate(512 512) scale(0.6464) translate(-515 -476.5)`。
- 输出 `Android-foreground-432.png` 与 `Android-background-432.png`，432px 对应 108dp 的 xxxhdpi（4×）密度；前景 RGBA，背景 RGB。前景像素最大半径实测约 **129.52px**，小于该输出中的 **132px** 安全半径。
- `Android-safe-zone.svg/png` 中，圆形虚线表示 66dp 安全圆，方形虚线表示中央 72dp 区域；辅助线只出现在规范图中。
- Android SVG 是可编辑设计源文件，不能直接作为 Android VectorDrawable XML 使用。接入 Android 工程时可使用按密度导出的 PNG，或将路径转换为 VectorDrawable，再通过 `<adaptive-icon>` 引用背景和前景。本项目为 iOS 工程，本次未创建 Android 工程或单色主题图层。

规范依据：[Android — Adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)、[Android — Change the app icon](https://developer.android.com/codelabs/basic-android-kotlin-compose-training-change-app-icon)，核对日期：2026-10-04。

## （4）配色方案

| 色系 | 色值 | 用途 |
|---|---|---|
| 暖橙 | `#F3B17B` → `#EFA16F` | 背景轻渐变，爱心复用渐变终点色 |
| 奶油白 | `#FFF5E7` | 狗狗头部、身体与对话气泡 |
| 可可棕 | `#654435` | 狗耳、五官、蝴蝶领结 |

从指定暖橙／奶油白／浅蓝中选用暖橙和奶油白两种主调，加可可棕作为第三色系，总计 **3 个色系、4 个实色色值**（暖橙渐变使用两个端点）。渐变及抗锯齿会生成中间像素颜色，不将其误称为只有三种像素颜色。

可可棕与奶油白的亮度对比约 8.0:1，用于维持五官的可读性；该数值是色值计算结果，不等同于图标识别率或可用性测试结果。

## （5）最终 SVG 矢量代码与分层设计规范

完整可编辑代码见 `AppIcon.svg`。只含原生 SVG 路径、椭圆、矩形和线性渐变；无嵌入位图、外链字体或外部素材依赖。`title`、`desc` 仅为不可见的无障碍元数据，图标画面中没有文字。

所有坐标均基于 1024×1024 画布，以下按绘制顺序由底至顶排列：

| 图层 ID | 几何与顺序 | 填充／描边 |
|---|---|---|
| `background` | 覆盖 `(0,0)` 至 `(1024,1024)` | 暖橙线性渐变；无阴影 |
| `foreground/social-bubble` | 原始路径范围约 x578–855；整体 y 平移 −64；气泡右上、尾尖左下 | 奶油白气泡、暖橙实心爱心，无描边 |
| `foreground/body` | x311–639，肩部自 y689 向下扩展，底部为轻弧线 | 奶油白 |
| `foreground/ears` | 左右两枚垂耳，头部后方 | 可可棕 |
| `foreground/head` | x247–695，y302–733；圆润贝塞尔头形 | 奶油白，无轮廓描边 |
| `foreground/expression` | 睁眼中心 `(379,495)`，眨眼 x535–593；鼻子与微笑居中 | 可可棕；眨眼 24px、嘴线 20px，圆头描边 |
| `foreground/bow-tie` | 左右翼 x387–555；中心结为 34×39px、圆角 12px | 可可棕 |
