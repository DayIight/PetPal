# PetPal App Icon 分层设计规范

适用文件：`AppIcon.svg`（1024×1024 主图）、`AppIcon-preview-light.svg` / `AppIcon-preview-dark.svg`（预览）。

---

## 1. 设计理念

PetPal 面向 20-35 岁都市养宠人群，是一款以"宠物"为纽带的社交产品。图标设计围绕三个关键词展开：

- **信任感**：暖橙色底传递可靠与温度，圆润无棱角的造型消除距离感；
- **温暖社区感**：猫与狗双宠同框、脸颊相贴——"每只宠物都有朋友"，双宠相依本身即是社区隐喻；头顶一颗爱心，点出"以宠爱相聚"的产品内核；
- **轻松愉悦**：扁平插画 + 轻微对角渐变，闭眼微笑的猫咪与温和注视的狗狗营造无压力的愉悦氛围。

设计刻意**不做拟人化**（无配饰、无拟人表情），以动物本身的亲和形态取胜，避免低龄化，贴合都市成年用户审美。

## 2. 视觉元素拆解

| 元素 | 造型说明 | 语义 |
|---|---|---|
| 狗狗（前层·左） | 奶油白圆脸、垂耳、圆点眼、鼻 + 自然嘴角弧线、浅色吻部 | 热情、忠诚、友善 |
| 猫咪（后层·右） | 浅蓝圆脸、尖耳（带浅色内耳）、闭眼笑弧、鼻 + ω 嘴、单侧胡须 | 安静、治愈、陪伴 |
| 相依构图 | 狗脸与猫脸约 170px 交叠，脸颊相贴 | 社交/伙伴关系 |
| 爱心 | 奶油白，位于双宠头顶中央 | 社区、喜爱、连接 |
| 腮红 | 低透明暖橙圆点 | 亲和、愉悦 |
| 背景 | 暖橙对角渐变 + 7% 白色柔光圆 | 活力、聚焦视觉中心 |

**60×60 小尺寸可辨性**：小尺寸下细节（胡须、腮红、嘴线）自然隐去，画面收束为"橙底 + 白狗 + 蓝猫 + 头顶爱心"四个大色块，物种与社交语义依然清晰（已实测 60px 渲染确认）。

## 3. iOS 与 Android 规范适配

### iOS
- 提交 **1024×1024 正方形、无圆角、无透明通道** 的 PNG（App Store Connect 与 Xcode Asset Catalog 均要求方图）；`AppIcon.svg` 即按全出血方图设计，导出时栅格化即可。
- 圆角由系统施加 **连续曲率（超椭圆）圆角**，视觉半径约为边长的 **22.37%**（1024 下 ≈ 229px）；图标四角不放置关键元素——本设计四角仅为纯色渐变底，天然安全。
- Xcode 15+ 支持 Asset Catalog 中单张 1024 全尺寸图标（Any Appearance），建议同时提供深色/染色变体时复用同一造型。
- 预览文件用 `clipPath` 以 22.37% 圆角矩形近似系统遮罩（连续曲率的近似，仅供效果参考）。

### Android（自适应图标规范说明）
- 自适应图标画布 108×108dp，由 **前景层** 与 **背景层** 两张图叠加；系统遮罩（圆形/圆角矩形/水滴等因厂商而异）只保证中央 **直径 66dp 的安全圆** 内内容可见。
- 分层建议：背景层 = 暖橙渐变纯色；前景层 = 双宠 + 爱心组合，整体缩放至 **62-66dp 直径以内**（即主视觉不超过画布中心 61%），四角不承载信息。
- 本设计主视觉集中于中央约 70% 区域，将双宠组合等比收缩 5-8% 即可落入安全区；心形位置偏上，收缩后仍距顶部边缘 ≥ 12dp，满足各厂商遮罩裁切。

## 4. 配色方案

主色严格 ≤3 种：

| 角色 | 色值 | 用途 |
|---|---|---|
| 暖橙（主色 1） | `#FF8C42` → `#FF6F3C` 135° 对角渐变 | 背景 |
| 奶油白（主色 2） | `#FFF4E6` | 狗狗主体、爱心 |
| 浅蓝（主色 3） | `#7EC8E3` | 猫咪主体 |

同色系功能色（不计入主色）：五官/描边深橙棕 `#5C3A2E`；狗耳深奶油 `#F0DFC2`；内耳浅蓝 `#A9DEF2`；腮红 `#FF9E5E`（35% 透明）。

**浅/深色背景表现**：图标为全出血暖橙底，在浅色（`#F2F2F7`）与深色（`#1C1C1E`）系统背景下均有充分明度差，边缘清晰、无"发灰"问题；深橙棕五官与奶油白/浅蓝主体的对比度在小尺寸下仍可分辨。见两份预览 SVG。

## 5. SVG 分层结构说明

`AppIcon.svg`（viewBox `0 0 1024 1024`）图层树（自下而上）：

```
<svg>
├─ defs > linearGradient#bgGradient   背景渐变定义
├─ g#background    渐变底 rect + 白色柔光圆
├─ g#cat           猫耳/内耳/头（后层）
├─ g#dog           垂耳/头/吻部（前层，压叠猫脸左侧）
├─ g#features      双宠五官、胡须、腮红（#5C3A2E）
└─ g#heart         头顶爱心
```

- 每层独立 `<g id>` 分组，注释完整，可直接在 Figma/Illustrator 中打开编辑或按层导出；
- 导出 iOS：整图栅格化为 1024×1024 PNG（无 alpha 圆角）拖入 Asset Catalog；
- 导出 Android 自适应图标：`#background` 单独导出为背景层，`#cat`+`#dog`+`#features`+`#heart` 合并并收缩至 62-66dp 安全圆内导出为前景层。
