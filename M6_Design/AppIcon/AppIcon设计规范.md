# PetPal App Icon 设计规范（莫奈印象派版 · 2026-10-04）

适用文件：`AppIcon-Monet-1024.png`（1024×1024 母版）、
`AppIcon-Monet-preview-light.png` / `AppIcon-Monet-preview-dark.png`（浅/深背景预览）、
`PetPal-Social/PetPalSocial.icon`（Icon Studio 合成图标，iOS 26+ 实际生效通道）。

---

## 1. 设计理念

延续"双宠相依 + 爱心"的核心叙事，画风由扁平插画切换为**莫奈印象派油画**：

- **治愈感**：奶油白垂耳狗与橘猫闭眼相依而眠，表情松弛，传递"被陪伴"的安全感；
- **温暖社区感**：头顶一枚奶油色对话气泡包裹暖橙爱心——宠物先成为朋友，
  主人因它们相遇；
- **艺术辨识度**：背景取自莫奈《干草堆》日落系列的杏橙 × 灰蓝配色，左下落日、
  远处干草堆剪影，破碎笔触（broken color）让图标在主屏幕上具有画廊般的辨识度。

## 2. 视觉元素拆解

| 元素 | 造型说明 | 语义 |
|---|---|---|
| 狗狗（左） | 奶油白 + 暖橙斑纹、垂耳、闭眼微笑 | 热情、忠诚 |
| 猫咪（右） | 橘色虎斑、尖耳、闭眼依偎、胡须 | 安静、治愈 |
| 相依构图 | 双宠头部相贴、前爪交叠于画面下 1/3 | 社交/陪伴 |
| 爱心气泡 | 奶油色圆角气泡 + 暖橙爱心，位于双宠头顶 | 交流、喜爱 |
| 背景 | 杏橙天空 + 雾蓝地面破碎笔触、落日、干草堆剪影 | 莫奈风格锚点 |

**小尺寸可辨性**：60×60 下笔触细节自然融合，画面收束为"暖橙底 + 双宠依偎剪影 +
头顶爱心气泡"三个大色块，物种与社交语义仍可辨认（已实测编译产物 60pt 渲染确认）。

## 3. 平台适配

### iOS（双通道，均需维护）

| 通道 | 文件 | 说明 |
|---|---|---|
| Icon Studio 合成图标 | `M6_Design/AppIcon/PetPal-Social/PetPalSocial.icon` | iOS 26+ 实际生效；单图层位图（`Assets/monet-icon.png`，scale=1 满画布），修改后需保持 `icon.json` 图层结构与原格式一致 |
| Asset Catalog | `PetPal/Assets.xcassets/PetPalSocial.appiconset/AppIcon.png` | 旧系统回退通道；1024×1024、无圆角、**无透明通道** |

两处内容必须保持一致（可用 MD5 比对）；图标为全出血方图，四角仅纯色天空笔触，
系统施加 22.37% 连续曲率圆角后无信息损失。

### Android（如需适配）
- 自适应图标 108×108dp：背景层取母版整体收缩至中心 66dp 安全圆内，
  或裁切母版中心区域作为前景层；四角笔触不承载信息，各厂商遮罩裁切安全。

## 4. 配色方案

油画调色，不设严格色数上限，整体维持高明度暖调：

| 角色 | 代表色 | 用途 |
|---|---|---|
| 暖橙家族 | `#F5A04E` ~ `#E8863C` | 天空、猫毛、爱心、落日 |
| 奶油白 | `#F7EDDC` | 狗主体、气泡 |
| 雾蓝 | `#7E90B8` | 地面、远景干草堆阴影 |

浅/深色背景表现：白底下图标边缘柔和融入；黑底下油画成为发光焦点、橙色更饱和；
两种场景均无边缘裁切问题（见两份预览图）。
