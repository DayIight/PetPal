## 1. 设计理念

延续"双宠相依"的核心叙事，在莫奈印象派笔触基础上做**极致减法**：

- **元素极简**：只保留猫与狗两个大头像，无对话气泡、无风景、无配饰，视觉零干扰；
- **色彩收敛**：象牙白 + 一点暖橘的两色体系，整体高明度，治愈而不甜腻；
- **情感内核**：白狗与橘猫闭眼贴脸微笑——"被陪伴"的安全感即产品的第一触感。

## 2. 视觉元素拆解（V2）

| 元素 | 造型说明 | 语义 |
|---|---|---|
| 狗狗（左） | 奶白垂耳、闭眼微笑、深褐鼻头为全图唯一重色 | 热情、忠诚 |
| 猫咪（右） | 浅橘虎斑、尖耳、闭眼贴脸、细胡须 | 安静、治愈 |
| 相依构图 | 双头占画面约 80%，脸颊相贴于中轴 | 社交/陪伴 |
| 背景 | 奶油色薄涂笔触，与主体融为一体 | 极简、聚焦 |

**小尺寸可辨性**：60×60 下笔触融合为"白狗 + 橘猫"两个贴脸色块，物种与亲昵姿态
清晰可辨（已实测编译产物 60pt 渲染确认）。浅色壁纸下边缘柔和近无边框，深色壁纸
下呈温润奶色发光块。

## 3. 平台适配

### iOS（双通道，均需维护）

| 通道 | 文件 | 说明 |
|---|---|---|
| Icon Studio 合成图标 | `M6_Design/AppIcon/PetPal-Social/PetPalSocial.icon` | iOS 26+ 实际生效；单图层位图（`Assets/monet-icon.png`，scale=1 满画布），修改后需保持 `icon.json` 图层结构与原格式一致 |
| Asset Catalog | `PetPal/Assets.xcassets/PetPalSocial.appiconset/AppIcon.png` | 旧系统回退通道；1024×1024、无圆角、**无透明通道** |

两处内容必须一致（可用 MD5 比对）；图标为全出血方图，系统施加 22.37% 连续曲率
圆角后无信息损失。

### Android（如需适配）
- 自适应图标 108×108dp：母版整体收缩至中心 66dp 安全圆内即可，主体集中、
  四角无信息，各厂商遮罩裁切安全。

## 4. 配色方案

油画薄涂，整体两色体系：

| 角色 | 代表色 | 用途 |
|---|---|---|
| 奶油白 | `#F5EEE0` ~ `#EDE3D0` | 背景、狗主体 |
| 暖橘 | `#E8A05C` ~ `#D98F4A` | 猫主体、狗耳尖 |
| 点睛重色 | `#6B4A38` | 鼻头、眼缝（极小面积） |

浅/深色背景表现：白底下柔和融入、浅灰底（`#F2F2F7`）下边缘可辨；黑底下为高明度
暖色块，对比充足，均无色彩断层。

## 5. 版本切换与维护

- 图标为位图（AI 生成 + 人工裁切修版），**无 SVG 分层源文件**；
- 切换版本（以 vN 为例）：

  ```sh
  cp M6_Design/AppIcon/AppIcon-Monet-vN.png PetPal/Assets.xcassets/PetPalSocial.appiconset/AppIcon.png
  cp M6_Design/AppIcon/AppIcon-Monet-vN.png M6_Design/AppIcon/PetPal-Social/PetPalSocial.icon/Assets/monet-icon.png
  ```

  替换后执行 `./scripts/build-ios.sh` 验证编译产物图标；
- 回切初版：将上述 vN 换成 `AppIcon-Monet-1024`（即 `1024` 版母版）；
- 更早的扁平版图标已从仓库清理，可从 git 历史（提交 `5368b5d`）恢复。
