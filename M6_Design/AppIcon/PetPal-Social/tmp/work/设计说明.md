# PetPal · 宠友对话

两个互相交叠的聊天气泡，同时也是一只奶油白小狗和一只赤陶色小猫。利用气泡尾巴表达交流，利用动物轮廓表达宠物社区。

- 背景：暖杏色 #EFA26F
- 小狗：奶油白 #FFF6E8
- 小猫：赤陶色 #A65339
- 表情：可可棕 #673F32
- 狗耳：浅杏色 #E4AE82

交付：1024×1024 方形 SVG / PNG，圆角 SVG / PNG 预览，4 个可编辑 SVG 图层。已目视检查 1024px、64px 和浅深背景展示，校验报告位于 tmp/reports。

这是新的独立设计方案；项目既有图标仅用于了解配色与产品语境，没有复刻既有图形。
