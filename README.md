PetPal 是无需注册的本地宠物日常与健康记录工具，支持 iPhone 和 iPad。通过「今日 / 记录 / 成长 / 我的」四个标签管理宠物档案、记录、提醒和健康资料，数据默认保存在本机 Core Data。

## 功能介绍

- **宠物档案**：管理多只宠物的物种、品种、生日、体重、头像、过敏源及兽医联系方式，随时切换当前宠物。
- **日常记录**：喂食、遛弯、训练、驱虫、疫苗、体检、美容、服药共 8 类预设模板，也可创建自定义模板；支持照片、备注、心情、历史补录与编辑删除，通过时间轴或日历回看，并按文字、类型及日期范围搜索筛选。
- **常用快捷**：每只宠物可保存最多 6 项常用记录内容，点击后预填新记录，核对并点保存后才记入历史；照片、旧日期计划和任务完成状态不会沿用。
- **提醒与待办**：支持每日、每周、每月、每年及一次性提醒，显示今日和逾期待办。填写并保存对应记录后完成该次任务，删除完成记录可恢复待办；疫苗、驱虫记录可关联下次提醒。
- **用药疗程**：整理主人已有的药名、用量说明、起止日期和每日 1–6 个时间，最长 180 天；支持暂停、恢复、结束及查看历史。每次服药需确认实际记录，也可明确标记“跳过，未服药”。
- **首次使用引导**：按「创建档案 → 保存第一条记录 → 设置提醒」完成入门，可跳过，也可从「我的」重新打开。
- **成长看板**：查看体重月／年曲线、多宠物体重对比、月度打卡热力图及疫苗／驱虫／体检时间线，管理手录体重；历史事件与下次计划分别显示。
- **就医 PDF**：按全部日期或自定义范围导出当前宠物的档案、过敏源、体重及疫苗／驱虫／体检／用药资料，支持系统分享。
- **医疗资料夹**：按宠物导入、整理、预览及分享 PDF、JPEG 和 PNG，可添加标题、日期、医院、备注，并关联同一宠物的健康记录。
- **照护交接卡**：保存饮食、日常照护、注意事项和紧急联系人，按需加入过敏信息、进行中的用药安排及兽医联系方式，预览后导出 PDF 给临时照护者。
- **完整备份与恢复**：导出全部宠物的数据库、照片及医疗文件，包含常用快捷、用药疗程与照护说明；支持恢复准备取消及每周本机自动备份，页面显示备份状态。
- **隐私与支持**：提供离线隐私说明和反馈模板；宠物资料无需上传到开发者服务器。
- **桌面小组件**：显示宠物头像与今日提醒，点击进入对应宠物的记录页；iOS 17 起可通过左右箭头切换宠物页面。

## 开始使用

1. 打开 App，在「今日」按引导创建第一只宠物；之后可在「我的」管理更多档案或切换宠物。
2. 在「记录」选择预设或自定义模板，填写内容后保存。补录历史事件时选择实际发生时间，再通过时间轴或日历查看。
3. 在提醒管理中选择类型、重复规则和时间。保存时可授权通知；没有通知权限仍可在 App 中查看待办。
4. 点击今日或逾期待办，填写并保存对应记录，完成本次任务。取消或保存失败时任务保持待办状态。
5. 在「成长」查看体重与健康时间线；在「我的 → 数据备份」定期导出完整备份。

## 常用记录与搜索

在「今日 → 管理常用快捷」添加记录类型，或将一条已保存记录设为常用，再填写名称和常用内容。每只宠物最多 6 项，保存的内容不会随最近记录自动变化；可在编辑时主动用最近同类记录重设。点击快捷项后，新表单采用当前时间，清除照片、任务完成关联及日期字段，仍需核对必填项并点保存。

在「记录」输入类型、模板名称、答案内容或备注文字，点筛选按钮选择记录类型或日期范围。筛选只针对当前宠物，日期包含开始和结束当天；清除搜索与筛选后回到时间轴或日历。

## 管理用药疗程

在「提醒管理 → 用药疗程」添加药名、主人填写的单次用量／说明、起止日期，以及每天 1–6 个不同时间。疗程包含首尾日期，最长 180 个日历日；这些内容用于记录已有安排，不生成用药建议。

点击疗程待办，填写实际服药记录后保存，或选择跳过本次并明确记录为未服药。暂停、结束和删除疗程会停止对应提醒，已保存历史记录保留。疗程通知使用滚动预排，与其他提醒共用最多 64 条待发送请求；请留意页面显示的安排截止日期，并定期打开 App 补排。

## 医疗资料与照护交接

在「我的 → 医疗资料夹」从文件导入当前宠物的资料。PDF 每份最多 20 MiB、200 页，不接受加密或无法读取的文件；JPEG／PNG 每张最多 10 MiB、最长边 4096 像素、总计 1600 万像素。PDF 保留导入文件，图片按方向归一化存储，文件以随机名称保存在本机。填写资料信息后保存，可选择同一宠物的健康记录作为关联；删除该健康记录只解除关联，医疗资料仍保留。

在「我的 → 照护交接卡」填写饮食安排、日常照护、注意事项和紧急联系人。点「保存并预览导出范围」核对内容；过敏信息、进行中的用药安排及兽医联系方式默认关闭，可逐项选择加入。生成 PDF 后预览，再通过系统分享发送。交接卡不附带芯片号、其他病历或医疗文件，已填写的紧急联系人会随照护说明导出，请核对接收方。

## 导出就医报告

在「成长 → 导出 PDF」选择全部日期或自定义范围，生成后通过系统分享面板保存或发送。报告固定使用当前宠物，日期范围包含首尾整天；档案和过敏源采用导出时的当前值，下次日期标为计划。

报告包含已填写的芯片号、兽医联系方式及健康内容，分享前请核对范围和接收方。报告用于就诊沟通，不提供诊断或治疗建议。

## 备份与恢复

在「我的 → 数据备份」导出 `.petpalbackup` 文件，并保存到 App 外的可信位置。恢复时选择备份文件，按页面提示确认；文件校验和恢复准备期间可以取消，进入数据库替换后会完成提交或回滚。

当前导出的完整备份格式为 v2，支持恢复 v1 旧备份。除档案、记录、提醒、体重和照片外，备份也包含常用快捷、医疗资料及其文件、用药疗程和照护说明。

本机每周自动备份保留两份。卸载 App 会同时清除本机数据及本机备份，因此仍需定期导出。完整备份包含全部宠物的资料、照片、医疗文件及已填写的联系信息，文件未加密，分享与存放时应妥善保管。

## 添加桌面小组件

在 iOS 主屏幕长按空白处，进入小组件列表并选择 PetPal，添加小号或中号卡片。iOS 17 起可通过箭头循环查看多只宠物，小组件记住上次查看的宠物；iOS 16 显示 App 当前宠物。

点击卡片或提醒进入对应宠物的记录页。真机共享数据需要 App 与 Widget 使用相同、有效签名的 App Group，配置方法见 [真机安装与验收教程](docs/release/zh-Hans/真机与TestFlight验收.md)。

## 构建与测试

本机需安装完整 Xcode 和 iOS Simulator 运行时。首次配置开发工具路径：

```sh
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

打开仓库中的 `PetPal.xcodeproj`，选择 `PetPal` scheme 和 iPhone／iPad 模拟器，再点击 Run。命令行构建：

```sh
./scripts/build-ios.sh
```

运行单元测试与 UI 测试：

```sh
./scripts/test-ios.sh
```

脚本默认选择可用的 iPhone 模拟器；也可通过 `PETPAL_TEST_DEVICE_ID` 指定设备。真机安装、签名配置和 TestFlight 验收步骤见 [操作教程](docs/release/zh-Hans/真机与TestFlight验收.md)。

修改工程配置时编辑 `project.yml`，再执行：

```sh
xcodegen generate
```

## 技术栈与模块

项目使用 Swift 5.9+ 工具链、Swift 5 语言模式和 SwiftUI，最低支持 iOS 16.0。界面采用 MVVM，业务数据通过 Repository 访问 Core Data；Repository 写库后通过 NotificationCenter 通知订阅方刷新。Core Data V4 的 `CDCareItem` 按宠物和类别保存常用快捷、医疗资料元数据、用药疗程及照护说明的 JSON，文件保存在 App 容器。图表使用 Swift Charts，小组件使用 WidgetKit。
