# M5 成长看板与就医报告

当前功能：多宠物体重月/年曲线、手录体重管理、体检来源体重同步、月度打卡热力图，以及疫苗/驱虫/体检历史与独立下次计划。

B5 导出入口：成长 → 导出PDF → 全部日期或自定义范围 → 生成并分享 PDF。导出固定为当前宠物；看板的多宠物对比选项不影响报告。健康记录按发生日期、体重按测量日期筛选，含首尾整天。读取失败显示错误，不用空报告代替失败。

报告包含当前档案（含过敏源、芯片号、兽医联系方式）、体重曲线和明细、疫苗/驱虫/体检/服药内容与备注。档案为导出时当前值，不表示所选历史期间的档案快照。下次日期标为未确认完成的计划，照片仅说明数量，不嵌入原图。

A4 页面采用固定黑字白底、页眉页码和 CoreText 可见字符分页，长字段可跨多页，空数据明确标注。每次导出使用独立临时路径，避免覆盖正在分享的报告。PDF 为就诊沟通资料，不提供诊断或治疗建议。

数据边界与 PDF 测试见 `MedicalReportTests.swift`；空数据、标准和长文本样例在根目录 `output/pdf/`。正式发布还需真机分享保存、低空间及性能验收。
