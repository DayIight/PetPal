# M5 成长看板、医疗资料与 PDF

支持多宠物体重月/年曲线、手录体重管理、体检来源体重同步、月度打卡热力图，以及疫苗/驱虫/体检历史与独立下次计划。医疗资料夹整理当前宠物的 PDF 和图片，照护交接卡用于向临时照护者分享主人填写的安排。

## 就医报告

入口：「成长 → 导出 PDF → 全部日期或自定义范围 → 生成并分享 PDF」。导出固定为当前宠物；看板的多宠物对比选项不影响报告。健康记录按发生日期、体重按测量日期筛选，含首尾整天。读取失败显示错误，不用空报告代替失败。

报告包含当前档案（含过敏源、芯片号、兽医联系方式）、体重曲线和明细、疫苗/驱虫/体检/服药内容与备注。档案为导出时当前值，不表示所选历史期间的档案快照。下次日期标为未确认完成的计划，照片仅说明数量，不嵌入原图。

页面采用 A4 黑字白底、页眉页码和 CoreText 可见字符分页，长字段可跨多页，空数据明确标注。每次导出使用独立临时路径，避免覆盖正在分享的报告。PDF 为就诊沟通资料，不提供诊断或治疗建议。

## 医疗资料夹

在「我的 → 医疗资料夹」点右上角「+」，从系统文件选择器导入 PDF、JPEG 或 PNG。填写标题、资料日期、医院和备注后保存，可选关联同一宠物的疫苗、驱虫、体检或服药记录。标题必填且最多 100 字，医院最多 200 字，备注最多 20,000 字。

| 文件类型 | 导入边界与处理 |
|---|---|
| PDF | 每份最多 20 MiB、200 页，拒绝加密、锁定或无法读取的文件；保留导入的文件内容 |
| JPEG / PNG | 每张最多 10 MiB、最长边 4096 像素、总计 1600 万像素；只接受单张静态图片，按方向归一化并重新编码为 JPEG 或 PNG |

资料列表按资料日期倒序显示，只属于当前宠物。打开一项可编辑元数据，点「查看原件与分享」使用系统预览和分享；删除资料也会清理对应本机文件。删除已关联的健康记录只解除关联，保留资料与文件；删除宠物会一并清理其资料。

`MedicalDocumentImporter` 在后台协调读取系统文件选择器授权的文件，按大小限制读取并校验，使用随机 UUID 文件名写入 `AvatarStore.directory`。取消导入或保存失败会清理新文件；成功保存后由 `MedicalDocumentRepository` 管理。元数据以 `MedicalDocument` 编码到 V4 `CDCareItem` 的 `medicalDocument` 类别，完整备份包含元数据和医疗文件。App 不自动解读医疗内容；原文件可能包含姓名、电话等信息，分享前应检查内容与接收人。

## 照护交接卡

在「我的 → 照护交接卡」填写饮食安排、日常照护、注意事项和紧急联系人，每项最多 20,000 字。点击「保存照护说明」保留本机内容，或「保存并预览导出范围」进入分享范围页。

范围页默认包含已填写的四项照护说明。过敏信息、进行中的用药安排和兽医联系方式默认关闭，可逐项开启并在页内预览；用药安排只包含当前日期处于起止日期内且未暂停或结束的疗程。紧急联系人是照护说明的一部分，会随已填写内容导出。

点「生成 PDF 并预览」后通过系统分享发送。交接卡固定属于当前宠物，展示昵称、物种、品种和已选择的内容，不附带芯片号、其他病历、医疗文件或其他宠物资料。至少填写一项照护说明或选择一项可分享资料后才能生成。

`CareInstructionsRepository` 在 `CDCareItem` 的 `careInstructions` 类别中为每只宠物保存一份照护说明。`CareCardSnapshot` 固定导出范围，`CareCardPDFBuilder` 复用就医报告的 `ReportPage`，提供 A4 分页、页眉和页码；每次导出生成独立临时文件，关闭预览后清理。交接卡中的安排由主人填写，不作为诊断或处方建议。

系统预览、分享保存、低空间和大文件操作的真机步骤见 [真机与 TestFlight 验收教程](../docs/release/zh-Hans/真机与TestFlight验收.md)。
